# SAN — The Northern Duke

에이티즈 산과 ‘북부대공’ 콘셉트에서 영감을 얻은 비공식 팬 에디토리얼 웹 엔딩.

## 실행

빌드나 계정 연결이 필요 없는 HTML/CSS/JavaScript 정적 페이지입니다.

```sh
python3 -m http.server 4173
```

http://localhost:4173 에서 확인할 수 있습니다.

## 디자인

- Polar Night `#101C29` · Glacier `#C6D5DC` · Frost `#F0EEE8` · Steel `#9AABBD`
- Cormorant Garamond / DM Sans / IBM Plex Mono
- 반응형 화면, Canvas 하프톤 인물 및 눈 입자, 재생, 콘셉트·출처 모달
- 시스템 움직임 줄이기 설정 반영
